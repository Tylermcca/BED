# FirstTask: change a settings preset

A self-authored catalog with Default and Practice presets. Default stays fixed; Practice can change within numeric limits while reserve stays below rounds. The adapter supplies the cross-field rule and a named snapshot check.

Start with [the first-task guide](../../docs/guide/first_task.md). It gives the intended release-zip open/edit/refuse/check/save/undo walk, without SDK or build steps for newcomers. Build and UI tests are UNRUN in this preparation; the sample is not claimed to be in a release zip.

Files: data/settings.json, schemas/settings.schema.json, FirstTaskAdapter.cs and FirstTask.csproj. No simulation, game content, new dependencies or public library API changes. BORROWED existing adapter/check wiring; INVENTED settings and task.
