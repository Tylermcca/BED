# 0.5 preview: offscreen UI-tree walkthrough

15 November 2026. Reviewed the locally assembled Windows x64 0.5.0-preview.1 package from main `7c0c9d0a`, then refreshed the two app executables with this card's fixes. The package inventory was complete; both executables reported **BED 0.5.0-preview.1**. Nothing was published.

Only recorded control labels, roles, values, parent branches, enabled reasons and bounds drove the steps. No game or editor window appeared. Projects, settings, package copies and observations stayed in temporary owned folders and were removed afterwards.

The packaged `bed-cli ui --json --script` handled the start screen and creation. Its isolated UI host does not supply saved-file Play. For process controls, an offscreen driver used the normal app's existing `Program.SetUp` host and the packaged sample files, with the same built libraries. This checks the recorded tree and real owned processes; it does not check Windows UIA delivery or spoken Narrator output.

## Findings kept explicit

- `round_friend` appears in both the Outliner and the scene's object list. Selecting within the **Outliner** parent branch disambiguates it. The CLI's label-only click helper cannot make that distinction; the offscreen app driver used the recorded parent branch.
- A disabled **Play** in `bed-cli ui` describes that tool's missing app host, not the standalone player's capability. The app-host walk above exercised the actual process controls.
- The initial package had no running-picture UI route. BED-PICTURES-ROUTE01 adds and checks the View menu panel in the current source; native Windows UIA and Narrator delivery still need a real screen-reader check.
- Native Windows UIA projection, Narrator announcements, focus delivery and spoken reading order remain outstanding. This offscreen walk does not close the release's real-screen-reader caveat.

## Changes and checks

Fixed the start-screen New game action, gave installed samples plain searchable row names, and shortened the live-values start button. Existing user project names and sample folder paths stay as saved. The [live-values guide](../guide/live_values.md) uses the new label.

The new start-screen regression failed before the fix. All seven `NewGameStarterTests` and four `Live02Tests` passed with Release builds and the ten-minute hang limit. The owned offscreen driver completed the routes above using recorded controls; it and its captures were removed after the walkthrough. No full suite or visible-window run was used.
