# BED 0.5: what is ready and what remains

Source review of BED main `fd6d742e`, 15 November 2026, against the [0.5 roadmap](../../ROADMAP.md#then-05-one-thing-done-well-the-running-game) and FUT-001 through FUT-009, with the [offscreen UI-tree walkthrough](0.5_walkthrough.md) recorded in `18b02eca`. This is a progress list, not a published release or a new full test run.

0.5.0-preview.1 was published on 15 November 2026 from `69885709` plus these notes. An earlier check of the package from `fd6d742e`: `python tools/package_release.py --out artifacts/preview05c-20261115-fd6d742e --rid win-x64` produced a 261.5 MB ZIP and checked it after unpacking into a fresh folder. Recipes, Checkers and First task opened; the level, physics island and 2D garden passed Play and Export checks; a newly created game played its saved winning target. The local connection and all three AI setup examples also passed. These are the packager's checks, with every game run without a visible window; the screen-reader limits below still apply. 

## Done

- **Start a playable game:** File > New game creates a small game with Gum screens, saved settings, source code and an included Windows player.
- **Connect your own AI app:** BED previews the connection change, backs up existing settings and can remove its entry; new projects include instructions for the assistant.
- **Build and open code:** build saved source, read errors and open the reported source line in your own editor.
- **Review an assistant's proposed edit:** the editor can check a proposed data change and let you accept or reject it; the remote assistant cannot accept its own proposal.
- **Prepare release paperwork:** Export adds credits, notices, licence records and an AI-content worksheet for you to review.
- **Find actions by name (FUT-008):** the command palette searches available actions and leaves internal commands out of its results.
- **Keep asset identities (FUT-009):** imported assets get lasting ids; moving the asset with its record preserves references, and prepared caches can be rebuilt.
- **Asset permission checks before AI use (FUT-005):** BED’s supported AI reads, pictures and live-value replies check asset records and refuse forbidden, unknown or unreadable permissions in plain words. See [content rights](../guide/content_rights.md).
- **Separate player and editor code (FUT-007):** bundled players load their game data without the editor. Checkers shares its rules through a small rules project, and [packaging checks player dependencies](../../tools/check_player_dependencies.py).
- **A future-ideas register (FUT-006):** [each later idea](../future.md) now has an origin, required support and status, reviewed at milestones.

## Partly done

- **See and try the running game:** pictures and live values work in the garden and physics island; the island can jump its first crate through picture requests or the selected body through Live values. The walkthrough exercised real headless Play and garden live values; a follow-up source/headless UI-tree check reaches **View > Game picture**, takes real pictures of both samples and stops each owned run. Pictures also remain available through supported assistant requests. Another game must add its own support.
- **One command system for everything (FUT-001):** data edits have checks, undo and replay; not every tool uses the same action list or exposes all the planned rules.
- **Plug-ins (FUT-002):** trusted extensions can register commands, panels and object types, with version checks; automatic package installation and picking compatible versions are not built.
- **Local AI tools (FUT-003):** your AI can read and edit checked data through the local connection; the older network-server plan with separate client approvals is not built.
- **A final 0.5.0 release:** the preview and its [release notes](notes_0.5_preview.md) are published, and the offscreen UI-tree walkthrough is recorded. Native Windows UIA delivery, Narrator announcements and reading order still need a real screen-reader check. The final release waits for the user’s approval; the stable download remains 0.4.0.

## Not started

- **An assistant inside BED (FUT-004):** there is no built-in local-model or cloud-model provider connection; use a separate AI app today. Proposal review already exists, but BED does not supply the assistant itself.

The missing future plug-in, server and model-provider pieces are older roadmap ambitions, not new requirements to add to the first 0.5 preview. The register separates current support from later work; the permission checks and bundled-player dependency guard are now in place.
