# BED guides

New to BED? Begin with **[Start here](start_here.md)**: ten minutes, no programming. Then try everyday editing, levels, Play and Export. If something goes wrong, see [Reporting a problem](reporting_a_problem.md). The later guides cover automation and building an editor for your own data.

## Open and edit

1. [Start here](start_here.md) - Open BED, change data, move an object in a level, play it and save, in about ten minutes. Then try the 2D and physics samples.
2. [Edit project data](data_workflow.md) - Use tables and forms, follow references, preview bulk edits and replace values.
3. [Make your first game with BED, Gum and an AI](first_game_with_ai.md) - Create a playable game, change its settings and screens, then build a small code change.
4. [Build a data editor](editing_data.md) - Connect schemas, tables and forms to your own document format.
5. [Your first settings change](first_task.md) - Change a setting, see a mistake caught, run the game's check, then save and undo.
6. [Edit a level](levels.md) - Add models, select objects, change transforms and work with groups.
7. [Prefabs](prefabs.md) - Place a reusable piece, change one copy, review an update, and add physics bodies.
8. [Flat levels](flat_levels.md) - Place, size, move and order sprites in a flat XY level.
9. [Assets](assets.md) - Import models and textures, read thumbnails and part details, and resolve asset problems.
10. [Keyboard guide](keyboard.md) - Find shortcuts, navigate controls and change your local bindings.
11. [Accessibility](accessibility.md) - Use keyboard controls, assistive tools, larger text and high contrast.
12. [Use a screen reader](using_a_screen_reader.md) - Use the documented command-line route with a screen reader.
13. [Change many rows](bulk_edit_recipe.md) - Preview a bulk field edit, check the result and keep the changes you want.
